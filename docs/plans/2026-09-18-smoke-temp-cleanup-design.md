# 测试临时目录清理

目标：`backy-ui-*` 和 `tauri-backup-smoke-*` 在成功、失败和进程被终止后清理，断电造成的残留在下次测试启动时回收。

两个脚本共用 `tools/smoke-temp.cjs`，避免重复实现进程归属识别和递归删除边界。每次创建临时目录时写入所有者 PID，并启动隐藏的独立清理进程。正常退出在 `finally` 清理；所有者被强制结束后由独立进程收尾。

清理仅允许系统临时目录直属、指定前缀和六位随机后缀的非链接目录。跳过仍活跃的所有者；历史无标记目录需验证 profile 或测试任务结构，且浏览器未占用。终止浏览器前核对完整 profile 路径，测试应用需同时匹配记录的 PID、父 PID 和可执行文件路径。文件占用重试后仍失败会报错，保留标记供下次回收。

验证覆盖正常清理、进程强制结束、活跃目录保护、未知目录保护和删除路径边界；运行界面冒烟测试验证真实 Edge 文件锁释放。真实应用测试不得干扰已运行的正式版实例。

用户备份、正式版 WebView2 数据和项目内截图产物不属于临时目录清理范围。

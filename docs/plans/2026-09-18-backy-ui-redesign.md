# Backy 浅色界面与动效修订

## 设计方向

针对界面装饰过重和动效单调的问题，采用浅色桌面工具布局。移除英文装饰、宣传标语、深色侧栏、状态卡渐变和数字闪烁。信息优先级仍为当前状态、下次执行、最近结果和任务目录。

## 五套外观

| 名称 | 配置键（兼容旧数据） | 视觉特征 |
| --- | --- | --- |
| 素白（默认） | graphite | 中性灰白、低饱和灰绿强调，日常使用 |
| 雾蓝 | ocean | 冷白底、浅蓝侧栏、蓝色操作态 |
| 鼠尾草 | forest | 轻柔绿灰底色、草绿色操作态 |
| 暖纸 | plum | 米白纸面、棕灰文字、较小圆角 |
| 浅杏 | calm | 杏白底色、陶土色操作态、柔和圆角 |

所有主题统一定义 bg/card/sidebar/border/text/muted/accent/accent-hover/accent-soft；控件跟随主题，不加载远程字体或资源。设置页使用界面缩略图预览主题，aria-pressed 标识选中状态。

## 字体与组件

采用 Segoe UI Variable Text + Microsoft YaHei UI 的本机字体组合；后备为 Microsoft YaHei + sans-serif。可替代组合为 Segoe UI + Microsoft YaHei，或 Noto Sans SC + sans-serif（本机安装后使用）。数字采用 tabular-nums，路径使用 Consolas。

间距以 4/8/12/16/24/32px 为主；页面标题 23px、状态标题 21px、正文 12–14px、辅助文案 11–12px。卡片圆角默认 9px，暖纸 5px、浅杏 12px。所有可操作控件保留 focus-visible、hover、按下和禁用状态。

## 动效

- 空闲：文件图标每 7 秒轻摆一次，期间大部分时间保持静止。
- 等待：时针每 4.8 秒短暂摆动，不用于表示真实当前时间；倒计时文本保持稳定。
- 备份中：两张小文件以 0.9 秒错位沿弧线落入托盘，托盘轻微承接回弹；此为工作状态动画，不表示实际完成百分比。
- 完成：勾线在 400ms 内画出，反馈保留 1.8 秒后回到等待或空闲。
- 失败：静态错误图标和明确文案，不抖动整个页面。
- 按钮按下轻微下沉，页面切换使用短暂淡入。

新备份启动时取消旧结果反馈和进度复位计时器。隐藏到托盘时暂停动画；离开首页时首页动画不可见、顶部扫描暂停；prefers-reduced-motion 下动画关闭且保留明确静态图标。

## 验证

`node tools/ui-smoke.cjs` 使用 Edge 无头浏览器和模拟接口验证，不读取真实备份目录。覆盖五套主题的切换保存、五页在 1120px/920px 下的布局、文件动画确实移动、状态切换、连续备份的计时器竞争、减少动态偏好、隐藏窗口及空状态。截图输出到 artifacts/light-ui。

测试仅覆盖前端展示和接口调用约定，不替代 Rust 备份流程测试。打包沿用既有低内存构建环境参数，不修改备份逻辑。

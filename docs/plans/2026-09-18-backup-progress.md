# 当前备份内容与进度

目标：概览状态卡片显示当前任务、正在处理的文件或目录，以及真实的任务处理进度；本地备份和夸克上传明确区分。

采用卡片内横向进度条。按当前阶段已处理任务数显示进度，文件总量未知时显示流动效果及已处理文件数，不额外遍历源目录估算百分比。每次进入扫描、比较、复制、清理、状态保存阶段前更新当前路径；后台每 500ms 推送最新快照，较长的单文件操作也能显示正确名称。

实施：
1. 在备份统计内附加只用于运行时的进度信息，历史统计格式保持兼容；使用现有回调更新运行快照。
2. 夸克目录同步增加独立的当前路径回调，上传阶段按任务数展示进度。
3. 概览卡片增加文件名、完整路径提示、进度条和阶段说明；支持隐藏窗口恢复、结果和连续运行状态。
4. 补充 Rust 进度事件测试与现有 UI / Tauri 冒烟检查，检查 1120 和 920 宽度截图。

验收：手动选择单任务、定时全任务、空目录、跳过未变化文件、失败、演练和上传阶段的计数/路径正确；完成或失败不会被旧进度覆盖；不写入真实用户备份数据。

## 改动与验证

- 前端：`app/renderer/index.html`、`styles.css`、`app.js`，新增卡片进度区域、真实阶段与路径展示，恢复运行状态并清除旧进度。
- 后端：`src-tauri/src/backup.rs`、`main.rs`、`quark.rs`，在操作开始前更新快照，通过现有 500ms 后台循环推送；`get_state` 返回实时快照，历史文件不新增进度数据。
- 测试：`tools/ui-smoke.cjs`、`tools/tauri-smoke.cjs` 和 Rust 单元测试。
- `npm test`：28 项通过；`npm run check` 通过。
- UI 冒烟：本地任务进度、夸克阶段切换、长路径、920 / 1120 宽度、结果和连续启动通过；截图位于 `artifacts/light-ui/running.png`、`small-progress.png`、`quark-progress.png`。
- Tauri 冒烟：真实事件到达渲染层、计数与所选任务相符、完成后快照清空、历史记录未增加进度字段，全部通过。使用独立测试应用标识 `com.local.backy.progress-smoke` 和临时数据目录，避开已运行的正式程序。
- 进度条表示当前阶段的任务处理比例，不是字节百分比；文件总量未知时不显示虚构百分比。夸克界面阶段使用模拟事件验证，未使用真实账号上传。

# 自定义备份排除规则

- 采用全局 `excludePatterns` 字符串数组，复用已有 glob 依赖及旧版默认规则，空数组明确表示不排除。
- 设置页按行编辑，提供常用名称快捷添加及显式保存，状态刷新不覆盖草稿，保存错误直接展示。
- 仅匹配各层级文件或目录的名称，保持大小写及隐藏文件匹配语义；拒绝路径、空规则及无效通配符。
- 本地备份和夸克上传启动时创建规则快照；排除目录不递归扫描，运行中修改只影响下次运行。
- 镜像清理保留排除项；为避免连带删除，含排除项的过期目录整体保留。
- 验收：旧配置默认值、保存重读、空规则、嵌套过滤、演练模式、已存在目标保护、错误规则拒绝，以及界面草稿和保存交互。
